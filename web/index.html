Step 02 — Sources

Local files

Add PDFs straight from this machine — single files or a whole folder. Each one is converted to text per page, split into overlapping chunks and stored twice: as text in the SQLite knowledge base, as embeddings in the vector store. Source file + page stay on every chunk, so results remain traceable to where they came from.

Step 04 — Manage

    
Knowledge bases

    
Each knowledge base is its own container: its own directory, database, vector
      store, exports and stored source copies, and its own embedding collection. Creating one gives
      it a fresh container — it never inherits the paths of the one you are in, and it can never
      read another one's files. Switching backs the current one up first.
